# Pip's Portfolio: Junior Dream Engineer at the Midnight Nursery

Entry for haX.baby "Baby's First Website", Track 1 (Same Baby, 1,000 Websites).

Static site, no build step: `index.html` plus `assets/` (four official Pip images, optimised to WebP).

## Run locally
Open `index.html` in a browser.

## Deploy on Netlify
Drag this whole folder onto https://app.netlify.com/drop, or connect the GitHub repo (no build command, publish directory `.`).

## Features
Scroll-revealed origin story, head tilts toward the cursor or finger, day/night toggle (sleepy eyes at night), Web Audio music box with keys and a mute toggle, glowing nightlight that switches the page to night, growth chart, sparkle trail, dreams-delivered odometer, hidden Easter egg (boop Pip's nose three times), `prefers-reduced-motion` support.
